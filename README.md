## 🌟 Overview

**TaskVerse** is a full-stack **MERN Todo Management Web Application** built to manage daily tasks with a clean, modern, and responsive UI.

Users can create, edit, delete, search, filter, and track tasks using priority, category, status, and due dates. Data is stored securely in **MongoDB Atlas**.

---

## ✨ Features

✅ Add new tasks  
✅ Edit existing tasks  
✅ Delete tasks  
✅ Search tasks  
✅ Filter by status  
✅ Filter by priority  
✅ Track due dates  
✅ Task statistics dashboard  
✅ Responsive UI  
✅ MongoDB Atlas cloud database  
✅ Render deployment ready
