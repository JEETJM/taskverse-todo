# 🚀 TaskVerse — MERN Todo Management App

![TaskVerse Banner](https://via.placeholder.com/1200x400?text=TaskVerse+MERN+App)

## 🌟 Overview

TaskVerse is a full-stack MERN (MongoDB, Express, React, Node.js) Todo Management Web Application designed to help users plan, organize, and track their tasks efficiently.

It features a clean UI, real-time updates, filtering, and cloud-based storage using MongoDB Atlas.

---

## 🔥 Features

* ✅ Add / Edit / Delete Tasks
* 🔍 Search & Filter (Status, Priority)
* 📊 Task Statistics Dashboard
* 📅 Due Date Tracking
* 🎯 Priority Levels (Low, Medium, High)
* 🌐 MongoDB Atlas Cloud Database
* ⚡ Fast & Responsive UI
* 🧠 Clean Architecture (MERN Stack)

---

## 🛠️ Tech Stack

**Frontend**

* React.js (Vite)
* Axios
* CSS3 (Custom UI)

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB Atlas

* Render (Backend + Frontend)

## ⚙️ Installation (Local Setup)

### 1️⃣ Clone Repo

```bash
git clone https://github.com/YOUR_USERNAME/taskverse-todo.git
cd taskverse-todo
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create `.env`:

```env
PORT=8080
MONGO_URI=your_mongodb_uri
CLIENT_URL=http://localhost:5173
```

Run backend:

```bash
npm run dev
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
